# AFROMODE - Boutique de Mode Africaine

## Présentation

AFROMODE est un site e-commerce responsive consacré à la vente de vêtements et accessoires de mode africaine contemporaine.

Ce projet a été réalisé dans le cadre d'un projet de développement web en utilisant uniquement HTML5, CSS3 et JavaScript.

---

## Technologies utilisées


- HTML5
- CSS3
- JavaScript (ES6)
- LocalStorage
- Font Awesome
- Google Fonts

---

## Fonctionnalités

### Accueil
- Présentation de la boutique
- Catégories
- Nouveautés
- Promotions
- Témoignages
- Newsletter

### Boutique
- Catalogue de 12 produits
- Recherche dynamique
- Filtres
- Tri des produits
- Vue Grille / Liste

### Produit
- Galerie d'images
- Choix de la taille
- Choix de la couleur
- Ajout au panier

### Panier
- Ajout/Suppression de produits
- Modification des quantités
- Calcul automatique du total
- Sauvegarde avec LocalStorage

### Commande
- Validation de la commande
- Confirmation

### Compte
- Inscription
- Connexion simulée avec LocalStorage

### Contact
- Formulaire de contact
- FAQ interactive

## Installation

1. Télécharger le projet.
2. Ouvrir le dossier dans Visual Studio Code.
3. Installer l'extension Live Server.
4. Cliquer sur "Go Live".
5. Naviguer sur le site.
